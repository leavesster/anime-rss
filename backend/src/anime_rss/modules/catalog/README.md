# 目录模块

负责稳定的动画标识、导入的元数据、别名，以及有界的 Bangumi 搜索缓存。其他模块只能使用 `api.py` 提供的 DTO。

目录同时提供本地标题解析：先匹配精确的 Unicode 标准化标题键，再使用 OpenCC 繁转简规范键进行唯一匹配。唯一命中返回本地 `anime_id`；多个动画共享同一标题键时返回歧义，不自动猜测。用户确认动画后，RSS 标题会写入显式绑定；显式绑定优先于自动匹配，同标题及其繁简变体后续都沿用用户选择。目录标题或绑定变化会发出事件，让现有 RSS 候选重新关联。

本模块还负责提供参考性的每周播出元数据。Bangumi 导入在存在数据时采用服务方给出的日本当地播出计划；管理员可以用明确的日期、时间和 IANA 时区覆盖该计划。

本模块不解析发布资源结构、不对候选项排序，也不创建下载决策。外部元数据仅供参考：RSS 识别只查询已经落库的本地目录，即使 Bangumi 不可用，本地动画记录和别名仍然可用。
